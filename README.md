# 开源社团 · 活动 / 项目 / 竞赛归档

本仓库用于集中留存和展示社团参与的竞赛、自研项目与社团活动的成果材料。仓库只收录**便于浏览和展示的内容**（介绍文档、图片、PDF、原始申报材料），源码不在此仓库，按条目中的链接跳转到对应源码仓库。

## 目录结构

```text
.
├─ README.md                 # 本文件：仓库说明与成果索引
├─ assets/                   # 全仓库共用素材（社徽、通用封面等）
├─ competitions/             # 竞赛
├─ projects/                 # 自研项目
├─ activities/               # 社团活动
└─ _template/                # 新条目模板
```

## 条目规范

1. **顶层按类型分目录**：`competitions/`、`projects/`、`activities/`。
2. **条目目录命名**：`YYYY-英文slug`，例如 `2026-huaweicloud-openharmony`。中文全名写在条目 `README.md` 的一级标题中。
3. **每个条目必须包含 `README.md`**，并填写元数据表（时间、类型、主办单位、赛道、成果、相关链接）。
4. **子目录统一编号**：`01-项目介绍.md`、`02-展示材料/`、`03-现场记录/`、`04-赛事资料/`，按实际内容裁剪。
5. **收录范围**
   - 收录：项目介绍、路演材料、现场照片、获奖证明、主办方通知与报名表等。
   - 不收录：源码、演示视频、编译产物。
   - `.pptx` 一律导出 PDF 后入库，保证网页可直接预览；`docx/xlsx` 保留原件。
6. **新增条目**：复制 `_template/` 到对应类型目录并改名，在本文件「成果索引」中追加一行。
